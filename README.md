Run Locally

Prerequisite: Node.js installed

bash
# 1. Clone the repository
git clone https://github.com/UNIQUE14320/Portfolio.git

# 2. Go into the folder
cd Portfolio

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev

If the app uses the Gemini API, create a .env.local file and add your key:

GEMINI_API_KEY=your_key_here
